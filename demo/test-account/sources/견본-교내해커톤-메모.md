# 교내 해커톤 「OO 메이커톤」 메모 (2024-11-16 ~ 11-17, 무박 2일)

팀 3명(나 · 같은 동아리 친구 · 디자인과 친구). 주제: 캠퍼스 생활을 바꾸는 서비스.

## 만든 것 — 「버스언제」
- 학교 앞 셔틀 · 시내버스 도착 시간을 한 화면에 모아 주는 웹앱. 수업 끝나는 시간을 넣으면 "지금 나가면 몇 분 기다림"을 보여 준다.
- 나: 백엔드(공공 버스 도착 API 연동, 셔틀 시간표 DB) + 마지막 발표. 동아리 친구: 프론트. 디자인과 친구: 화면 · 발표 자료.

## 막힌 것
- 새벽 2시쯤 공공 API 호출 한도(분당 호출 수)에 걸려 화면이 빈칸이 됐다. 사용자마다 그때그때 부르고 있었다.
- 내가 30초짜리 캐시를 두고 정류장 단위로 한 번만 부르게 바꿨다. 호출 수가 사용자 수와 상관없어져 한도에 다시 걸리지 않았다.
- 대신 도착 시간이 최대 30초 늦게 보인다 — 발표 때 이 한계를 먼저 말했다.

## 결과
- 장려상(18팀 중). 심사 의견: "실사용 문제를 좁게 잡았다. 셔틀 시간표를 학교가 바꾸면 손으로 고쳐야 하는 점은 아쉽다."

## 아쉬운 것
- 셔틀 시간표를 손으로 넣었다. 학교 홈페이지 공지가 PDF 라 자동으로 못 읽었다.
- 시간 배분: 첫날 저녁까지 기능을 너무 많이 잡아 발표 준비가 1시간밖에 없었다. 다음엔 "발표 3시간 전에 기능 동결".
