# 알고리즘 스터디 기록 (2024-09 ~ 진행 중)

동아리 사람 5명, 매주 일요일 저녁 온라인 1시간 반.

- 내가 문제 선정을 맡는다. 매주 같은 유형 3문제(쉬움 · 보통 · 어려움)를 골라 화요일까지 올린다.
- 처음엔 다들 어려운 문제에서 막혀 일요일에 답만 보고 끝났다. 2024-11 부터 "막힌 지점까지 쓴 코드와 생각"을 먼저 공유하고, 푼 사람이 힌트만 주는 방식으로 바꿨다(내 제안, 투표로 결정).
- 2025-08 기준 내가 푼 문제 약 320개. 백준 티어 실버 → 골드 2.
- 2025-03 에 그래프 · 최단 경로 유형을 6주 묶음으로 따로 진행했다. 이때 정리한 다익스트라 · 플로이드 노트를 스터디 노션에 올렸고, 다른 스터디원 2명이 코딩 테스트 준비에 썼다고 했다.
- 2026-03 부터 취업 준비로 2명이 빠지고 3명이 격주로 하는 중.
