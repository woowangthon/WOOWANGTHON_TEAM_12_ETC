# ADR-008: MCP 서버와 도구는 BE 한 곳에 — 차곡이도 그 MCP 의 클라이언트

- 상태: 채택
- 날짜: 2026-11-04

## 배경

- 데모 7(S-32)이 `P0` 가 됐다 — Claude 같은 다른 AI 에서 내 경험을 검색한다. MCP 서버를 어디에 둘지(SPEC 미결정 18) 정해야 BE · FE 가 시작할 수 있다(계약 `docs/contracts/mcp-api.md`, BE#41 · FE#57).
- [ADR-007](ADR-007-chagok-entrance-agent.md) 은 차곡이(S-31, AI 서버 · 파이썬)와 MCP 가 **같은 도구 목록**을 쓴다고 했다. 두 곳에 따로 정의하면 도구가 늘수록 어긋난다(SPEC 미결정 21).
- MCP 서버는 흔히 파이썬(FastMCP)으로 만든다. 하지만 이번 MCP 는 AI 를 쓰지 않는다 — 토큰을 확인하고 DB 에서 경험을 읽어 JSON-RPC 로 돌려줄 뿐이다. 토큰 · 사용자 · 데이터 · 사용 한도는 BE 에 있다.
- AI 서버는 내부망 전용이고([ADR-004](ADR-004-deploy.md)) DB 를 만지지 않는다([ADR-003](ADR-003-stack-and-ai-boundary.md)).
- 기획(Notion 기획-v261101 6장)은 MCP 를 읽기 → 쓰기(ETC#27) → OAuth · REST 개인 토큰(ETC#87) · 우리 AI 기능을 도구로(ETC#88)까지 넓힌다. 그때마다 갈아엎지 않을 자리가 필요하다.

## 결정

- **MCP 서버는 BE 에 둔다** — `POST /mcp/{token}`(계약 `mcp-api.md`). 라이브러리(Spring AI MCP 등)를 쓸지 직접 받을지는 BE 가 정한다.
- **도구는 BE 의 MCP 서버에만 정의한다.** 도구 하나 = 코드 한 곳. 입력 · 결과 모양은 `mcp-api.md` 가 원본이다.
- **차곡이 도구 루프(S-31)는 그 MCP 에 붙는 클라이언트다.** AI 서버가 MCP 클라이언트(파이썬 SDK)로 `tools/list` 를 받아 LLM 함수 호출에 넘기고, `tools/call` 로 부른다. 안에서는 차곡이가, 밖에서는 사용자의 AI 가 **같은 문**으로 들어온다.
- AI 서버의 내부 호출 인증(「사용자 X 를 대신해」)은 S-31 을 시작할 때 BE · AI 가 정해 계약에 더한다 — 내부망 경로로만 받는다.
- 연결은 일반 「접근 토큰」으로 저장한다(여러 행 · `scope` · 이름 — BE#41). 쓰기 권한 · 클라이언트별 연결 · OAuth · REST 개인 토큰이 같은 자리에 들어온다.
- 외부 AI 의 쓰기(ETC#27)는 경험을 직접 고치지 않고 원본으로 들어와 지금의 추출 · 근거 대조를 거친다.

영향: SPEC 미결정 18 · 21 을 닫는다. `architecture.md` 레포 표 · `mcp-api.md` 머리말.

## 버린 안

- **AI 레포에 파이썬 MCP 서버(FastMCP)** — MCP SDK 가 가장 익숙하고 차곡이와 같은 언어다. 하지만 내부 전용 AI 서버를 밖에 열어야 하고, DB 를 못 만지니 BE 에 내부 API 를 하나 더 만들어 거쳐야 하며, 토큰 확인도 결국 BE 가 한다 — 홉 · 인증이 두 겹이 된다.
- **도구를 AI 서버와 BE 에 따로 정의(두 벌)** — 차곡이가 MCP 를 거치지 않아 한 단계 빠르다. 하지만 도구를 더하거나 고칠 때마다 두 곳을 맞춰야 하고, 「같은 도구 목록」이 말뿐이 된다.
- **MCP 를 따로 새 레포 · 새 서비스로** — 경계가 깔끔하다. 하지만 11-15 까지 배포 단위를 하나 더 늘릴 여유가 없다.

## 결과

- 「경험은 사용자 것이라 어디서든 쓴다」가 구조로 보인다 — 우리 AI 도 사용자의 AI 와 같은 도구를 쓴다(발표 · 기술 설계).
- MCP 읽기는 LLM 을 부르지 않는다 — 하루 분석 한도에 세지 않는다.
- 포기한 것: 차곡이 호출이 HTTP 한 번을 더 거친다(내부망이라 작다). 파이썬 MCP SDK 의 편의를 BE 에서 못 쓴다.
- 남은 위험: Spring AI MCP 가 Spring Boot 4 와 맞는지 미확인(안 맞으면 메서드 다섯 개를 직접 받는다). 운영 API 가 Cloudflare Access 뒤라 `/mcp/*` 우회가 필요하다(BE#21 · 서버 담당).
