# ADR-018: 구분은 데이터에 두고, 화면엔 예외만 보인다 — STAR 는 BE 가 알아서 정리

- 상태: 채택
- 날짜: 2026-11-11

## 배경

- PM 이 배포본을 직접 쓰며 화면을 점검했다(ETC#346). 출처 상태(원문 확인 · 내가 입력 · 확인 필요) · 되묻기 질문 · 「빠진 것」 · STAR 진행 같은 **내부 구분이 화면에 그대로 드러나** 글자가 많고 할 일이 안 보였다. PM: 「정리된 건 사실로 치고 쓰면 되지 않나」 「12개 채워야 하는 걸로 강요하는 느낌」 「STAR 정리는 우리가 내부적으로 자동으로 해야 하지 않나」.
- 이 구분은 데이터로는 꼭 필요하다 — 초안 근거(S-27) · 외부 AI 변경의 「맞아요」(S-53) · Markdown 내보내기(S-33)가 이걸로 돈다. SPEC §0 의 차별점이기도 하다.
- ADR-017 은 STAR 를 채우지 않고 빈칸을 묻기로 했지만, 이미 쌓인 경험은 사용자가 활동마다 「STAR 로 정리」(분석 1회)를 눌러야 했고 홈 · 서랍에 「차곡이가 물어볼 게 N개」를 두었다.

## 결정

- **구분해 저장하고, 화면엔 사실이 아닌 것만 표시한다** — AI 해석(역량 · 분류 · 문항 유형 · 추천 이유) · 초안 「AI 가정」 · 「확인 필요」. 원문에서 확인 · 내가 입력은 둘 다 사실이라 평소 표시하지 않고, 근거는 원본 칩을 눌러 본다. 밖으로 나가는 글(Markdown 내보내기)엔 구분을 글자로 남긴다. SPEC §0 · 용어 「출처 상태」 · S-08 · S-58 · S-83 · S-23.
- **STAR 는 ADR-017 의 규칙을 그대로 잇는다** — 경험별 네 칸, 근거 발췌 · 보완 글로만 채우고 코드로 대조, 배운 점은 사용자 답으로만, 기본은 접힘. 바뀌는 것은:
  - 이미 쌓인 경험(`NONE`)과 근거 · 보완이 바뀐 경험(`STALE`)도 **BE 가 알아서 정리하고 분석 횟수를 세지 않는다.** 「STAR 로 정리」 · 「다시 정리」 버튼을 없앤다. `FAILED` 만 「다시 시도」(세지 않음). 미결정 31 을 닫는다.
  - 빈칸은 질문을 안내 글로 품은 입력칸이고, 칸 출처 꼬리표(「원문 / 내 답」) · 답하기 폼 · 안내 문장을 두지 않는다 — 되묻기 답하기와 직접 고치기가 한 동작.
  - 홈 · 서랍의 「차곡이가 물어볼 게 N개」(S-97)를 없앤다. 「확인할 것 N」은 0 이면 숨긴다.
- 같은 결로 추천 카드의 강조점 · 「빠진 것」 · 근거 발췌를 화면에서 뺀다(S-20) — 부족한 사실은 차곡이 되묻기 한 곳에서만 묻는다.

영향: SPEC §0 · R-01 용어 표 · S-08 · S-20 · S-23 · S-58 · S-83 · S-95 ~ S-97 · 미결정 31, 계약 `experience-api.md` 「STAR 칸」 · README `starStatus`, DESIGN.md(경험 줄 · STAR 칸 · 홈 · 서랍 · 지원 화면). 레포 FE(FE#510 · #512 · #513 · #514 · #515) · BE(BE#180).

## 버린 안

- **지금처럼 모든 경험에 세 출처 상태를 글자로** — 무엇이 확인된 사실인지 늘 보인다. 하지만 두 사실 상태를 가르는 글자가 화면 대부분을 차지하고, 사용자가 그 구분으로 하는 일이 없다.
- **구분 자체를 없애기** — 가장 단순하다. 하지만 초안 근거 · 맞아요 · 내보내기 규칙이 무너진다(§0 「지어내지 않는다」).
- **STAR 를 사용자가 활동마다 눌러 정리(분석 1회 — ADR-017)** — 한도를 지킨다. 하지만 안 누르면 칸이 생기지 않고 「정리할 경험 N개」가 숙제처럼 남는다.
- **홈 · 서랍에 빈칸 수(S-97)** — 쓸수록 쌓인다를 보인다. 하지만 경험이 늘면 같이 커져 §0 「빈칸 채우기 압박을 두지 않는다」와 부딪친다.

## 결과

- 화면 글자가 줄고 「확인 필요」 · AI 해석만 눈에 띈다.
- 이미 쌓인 경험을 몰아 정리하는 유료 API 호출이 한 번 몰린다 — 사용자 분석 한도 밖이라 BE 가 동시 호출 수 · 상한을 둔다(BE#180).
- 「원문에서 확인」을 화면에서 볼 수 없으니, 근거가 있는지는 원본 칩이 있는지로만 보인다.
