# 경험 동료(가칭) 디자인 시스템 — 초안 1

> ETC#7. 화면을 만드는 사람 · 에이전트(FE · 디자인 도구)가 먼저 읽는 원본. 견본은 [`timeline.html`](timeline.html).
> 색 · 배치 · 문구는 담당이 정하고 PM 이 화면을 보며 고친다(ADR-002) — 고치면 이 파일을 같이 고친다.
> 출발점: getdesign.md 의 Airbnb DESIGN.md 에서 **「흰 바탕 · 한 색을 아껴 쓰기 · 그림자 한 단계 · 부드러운 모서리」 방식만** 빌렸다. 브랜드 · 글꼴 · 색값은 가져오지 않았다.

## 개요 — 이 서비스의 화면이 지켜야 할 것

- **경험 카드가 주인공이다.** AI 가 자료에서 활동 · 경험을 채워 주지만, 저장된 경험은 **사용자의 기록**이다. 그 자리에서 바로 고치고, 더하고, 지울 수 있어 보여야 한다.
- **근거는 뒷받침이다.** 원문 발췌 · 출처 상태는 필요할 때 펼친다. 단, 「원문에서 확인 / 내가 입력 / 확인 필요」 구분과 「AI 가 붙인 해석(역량)」 표시는 지우지 않는다(SPEC §0 · ADR-002 고정 항목) — **낮출 뿐이다.**
- **기록을 재촉하지 않는다.** 빈칸 · 점수 · 스트릭 · 빨간 숫자 배지 없음. 몇 달 만에 와도 편한 화면.
- **친근함은 문장과 여백에서.** 색을 늘려서 친근하게 만들지 않는다. 정보 구조는 차분하게.

## 색

한 화면의 90% 이상은 흰 바탕 · 먹색 글 · 따뜻한 회색이다. 색은 **역할이 있는 곳에만** 쓴다.

| 토큰 | 값 | 쓰는 곳 | 쓰지 않는 곳 |
| --- | --- | --- | --- |
| `primary` 산호 | `#E24947` | 주 버튼(「자료 넣기」) · 고른 활동 · 진행 중 점 | 넓은 면, 경고 · 오류, 본문 강조 |
| `primary-soft` | `#FDEDEC` | 고른 활동 줄 바탕 · 기간 띠 | |
| `evidence` 짙은 청록 | `#0B5A68` | 근거 열기 · 원본 파일 이름 · 「원문 확인」 표시 — **「원문 · 근거」의 색** | 버튼 · 장식 |
| `review` 호박 | `#9A5410` 글자 / `#FDF1E3` 바탕 / `#E9A35A` 점선 | 「확인 필요」 하나에만 | 다른 상태 |
| `error` | `#B4321F` | 분석 실패의 이유 글자 · 아이콘 | 면 칠하기 |
| `ink` · `body` · `muted` | `#23201F` · `#3E3937` · `#6E6562` | 글자 단계 | 순수 검정 · 순수 회색 |
| `hairline` | `#E6E1DE` | 줄 구분 · 패널 경계 | |

- **산호는 한 화면에 두 곳까지**(주 버튼 + 고른 활동). 셋째가 필요해 보이면 굵기나 크기로 바꾼다.
- 중립 회색은 모두 산호 쪽으로 살짝 따뜻하다 — 차가운 회색(`#6B7280` 류)을 섞지 않는다.
- 산호 위 흰 글은 15px 이상 · 600 굵기에서만(대비 4.0).
- 어두운 화면은 스프린트 1 에서 만들지 않는다.

## 글자

Pretendard 하나. 굵기는 낮게 — 위계는 크기와 여백이 만든다.

| 토큰 | 크기 / 굵기 | 쓰는 곳 |
| --- | --- | --- |
| `display` | 26 / 700 | 화면 제목(「내 경험」) — 화면에 하나 |
| `title-lg` | 21 / 650 | 세부의 활동 이름 |
| `title-md` | 17 / 600 | 연도 · 묶음 제목 · 활동 줄 이름 |
| `body-md` | 16 / 400 · 1.6 | **경험 본문** — 가장 많이 읽는 글 |
| `body-sm` | 14 / 400 | 기간 · 부가 정보 · 발췌문 |
| `label` | 13 / 500 | 메타 줄(주체 · 역량 · 상태), 작은 링크 |
| `badge` | 12 / 600 | 「확인 필요」 · 「AI」 같은 표시 |

- 숫자(연도 · 기간 · 개수)는 `font-variant-numeric: tabular-nums`. 고정폭 글꼴은 쓰지 않는다.
- 기간 표기는 `2025.03 – 2025.06`, 진행 중은 `2024.09 – 진행 중`.

## 배치 · 간격 · 모서리 · 그림자

- 간격은 4 의 배수: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. 묶음 안은 8~12, 묶음 사이는 24~32.
- **카드보다 구분선.** 목록(활동 줄 · 경험)은 상자로 감싸지 않고 `hairline` 한 줄로 나눈다. 상자는 떠 있는 것(패널 · 시트 · 메뉴 · 대화창)에만.
- 모서리: 버튼 · 입력 8, 떠 있는 상자 14, 하단 시트 위쪽 20, 꼬리표 full.
- 그림자는 `float` **한 단계**뿐 — 메뉴 · 시트 · 대화창 · 끄는 중인 카드. 나머지는 평평하다.
- 덮개(모달 뒤)는 `scrim` 45%.

## 아이콘

- **Phosphor Regular 한 세트**만. 직접 그리지 않고, 다른 세트를 섞지 않는다.
- 의미가 있는 곳에만: 근거(`quotes`) · 파일(`file-text`) · 확인 필요(`warning-circle`) · 고치기(`pencil-simple`) · 추가(`plus`) · 메뉴(`dots-three`) · 닫기(`x`) · 다시 시도(`arrows-clockwise`) · 끌기(`dots-six-vertical`).
- 제목 옆 장식 아이콘, 이모지, 반짝이(✨) 아이콘 없음.

## 컴포넌트

### 위 막대 `top-nav`
흰 바탕, 높이 64, 아래 `hairline`. 왼쪽 이름(가칭), 가운데 메뉴(타임라인 · 다음 스프린트 메뉴는 흐리게), 오른쪽 주 버튼 「자료 넣기」.

### 연도 묶음 `year-group`
연도(`title-md`, tabular) + 「활동 N」(`label` muted). 최근 연도가 위.

### 활동 줄 `activity-row`
- 한 줄: 이름(`title-md`) · 기간(`body-sm` muted) · 「경험 N」 · 오른쪽에 **기간 띠**.
- **기간 띠** `period-band`: 그해 1–12월을 12칸으로 나눈 얇은 띠(높이 6). 활동한 달은 `primary-soft` 위에 산호 50%, 진행 중이면 오른쪽 끝을 흐리게, 해를 넘으면 끝을 막지 않는다. 같은 연도의 띠가 세로로 줄지어 있어서 **겹침은 띠끼리 비교해 읽는다**(S-07).
- 해를 넘는 활동은 다음 해 묶음에도 **흐린 줄**(이름 · 「2024년부터」 · 띠)로 나온다 — 띠를 나란히 봐야 겹침이 읽혀서. 경험 수 같은 세부는 반복하지 않는다.
- **놓을 곳**(끌어다 놓기, P1): `ink` 점선 테두리 + `surface-strong` 바탕 + 안내 한 줄 「여기에 놓으면 이 활동으로 옮겨요」.
- 기간을 모르는 활동은 맨 아래 「기간 모름」 묶음.
- 호버 `surface-soft`, 고른 줄 `primary-soft` 바탕 + 이름 `primary-active`.

### 활동 세부 `activity-detail`
- PC: 오른쪽 패널(폭 440, `hairline` 경계, 타임라인은 옆에 남는다). 모바일: 전체 화면, 위에 「‹ 타임라인」.
- 머리: 활동 이름(`title-lg`) + 고치기 · 메뉴(⋯: 다른 활동과 합치기 P1) / 기간 / **「이 활동을 만든 자료」** — 근거들의 원본 이름을 모아 `evidence` 색 파일 링크로.
- 몸: 경험 목록. 처음 3개 + 「나머지 N개 더 보기」. 맨 아래 「+ 경험 직접 추가」(S-11, P1).

### 경험 `experience-item` — 주인공
```
채팅 메시지가 늦게 도착하는 문제를 폴링에서 WebSocket 으로      ⋯
바꿔 해결했다                                            ← body-md, 누르면 바로 고치기
나 · [AI] 문제 해결 · ✓ 원문 확인              ❝ 근거 1  ⌄    ← label muted / evidence
```
- 상자 없이, 경험 사이는 `hairline`.
- **메타 줄**(label, muted): 수행 주체 글자(나 · 팀 · 알 수 없음) · 역량(0 ~ 3개, 앞에 작은 「AI」 표시 하나 — AI 가 붙인 해석이라는 뜻) · 출처 상태.
- **출처 상태 표시** — 색만이 아니라 아이콘 · 글자로(S-08):

  | 상태 | 표시 |
  | --- | --- |
  | 원문에서 확인 | `evidence` 색 체크 + 「원문 확인」 — 작게 |
  | 내가 입력 | muted 연필 + 「내가 입력」 — 고쳤거나 직접 넣은 경험 |
  | 확인 필요 | **유일하게 색이 있는 꼬리표** — `review-soft` 바탕 · `review-line` 점선 · 느낌표 + 「확인 필요」 |

- **고치기**(S-10): 본문을 누르면 그 자리에서 입력칸이 되고 「저장 · 취소」. 저장하면 상태는 「내가 입력」, 근거는 그대로 남는다(계약: `PATCH /api/experiences/{id}`).
- **⋯ 메뉴**: 고치기 · 다른 활동으로 옮기기(P1) · 지우기(P1, S-11).
- PC 에서는 경험 왼쪽에 호버 때만 끌기 손잡이(P1, S-12).

### 근거 `citation`
- 「❝ 근거 N」을 누르면 경험 아래에 펼친다(모바일은 하단 시트).
- `surface-soft` 면 안에: 파일 이름(`evidence`, `label`) · 「5번째 줄」(muted) · 발췌문(`body-sm`, 왼쪽 `hairline` 세로줄).
- `matched: false` 면 발췌문 아래 `review` 글자로 「원본에서 이 문장을 그대로 찾지 못했어요. 맞는지 확인해 주세요.」

### 떠 있는 것 — 하단 시트 · 메뉴 · 대화창 · 알림
흰 면 · `float` 그림자. 알림(토스트)은 `ink` 면 · 흰 글 · 「되돌리기」 글자 버튼.

## 상태 화면

말투는 「~해요」. 가운데 정렬 덩어리 하나, 아이콘은 하나만.

| 상태 | 제목 | 할 수 있는 것 |
| --- | --- | --- |
| 첫 사용(활동 0) | 어떤 일을 해 왔나요? | 자료 넣기 — README · 회고 · 노트 예시를 회색 꼬리표로 |
| 분석 중 | 자료에서 활동과 경험을 찾고 있어요 | 파일 이름 · 단계(저장 → 찾기 → 근거 대조) · 「창을 닫아도 이어져요」 |
| 기존 타임라인 위 분석 중 | 위에 얇은 띠 하나 | 끝나면 활동이 더해진다 |
| 실패 | 분석하지 못했어요 | 이유 한 줄(`error`) · 「자료는 저장돼 있어요」 · 다시 시도(주) |
| 완료인데 활동 0 | 이 자료에서는 활동을 찾지 못했어요 | 「자료에 없다고 경험이 없는 건 아니에요」 · 다른 자료 넣기 |

## 반응형

| 폭 | 바뀌는 것 |
| --- | --- |
| < 744 | 타임라인 목록 → 활동을 누르면 전체 화면 세부 → 근거는 하단 시트. 「자료 넣기」는 오른쪽 아래 떠 있는 버튼. 옮기기는 ⋯ 메뉴로(끌기 없음) |
| ≥ 1024 | 목록 + 오른쪽 세부 패널. 끌어다 놓기로 옮기기(P1) |

터치 대상은 44 이상.

## 말투

- 사용자 쪽 말로: 「경력 데이터 등록」 대신 「어떤 일을 해 왔나요?」, 「역량 부족」 대신 「확인해 보면 좋아요」.
- 칭찬 · 과장 · 단정 없음(「대단해요」 「핵심 역량」 금지).
- 오류는 무슨 일이 있었는지 + 무엇을 하면 되는지. 사과문 없음.

## 하지 말 것

- 상태 · 역량 · 주체를 모두 색 알약으로 — 색이 있는 꼬리표는 「확인 필요」 하나
- 산호를 세 곳 넘게, 산호를 경고색으로
- 모든 블록에 같은 둥근 상자 + 그림자
- 크림 · 베이지 바탕, 고정폭 글꼴 장식, 그라데이션, 반짝이 아이콘
- 마인드맵 · 그래프 모양(SPEC F-03)
