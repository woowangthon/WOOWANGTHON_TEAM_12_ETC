# 차곡(가칭) 디자인 시스템 — 초안 2

> ETC#19. 화면을 만드는 사람 · 에이전트(FE · 디자인 도구)가 먼저 읽는 원본. 지금 모습은 FE 미리보기가 견본이다(FE#41). `timeline.html` 은 초안 1 견본으로 남겨 둔다.
> 색 · 배치 · 문구는 담당이 정하고 PM 이 화면을 보며 고친다(ADR-002) — 고치면 이 파일을 같이 고친다.
> 초안 1(흰 바탕 · 산호 한 색)은 PM 임시안이었다. 2026-11-03 디자인 담당 시안(https://woowangthon.vercel.app/)을 검토하고 방향을 바꿨다 — 무엇을 왜 바꿨는지는 ETC#19 첫 댓글.

## 개요 — 이 서비스의 화면이 지켜야 할 것

- **일상과 취업 사이.** 취업 사이트처럼 딱딱하지 않고, 일기 앱처럼 기울지도 않는다. **말투 · 색 · 모서리는 친근하게, 보여 주는 내용 · 정보 구조는 차분하고 실용적으로**(기획 7.2). 감정 · 계기는 받아 두되 강조하지 않는다.
- **경험이 주인공이다.** AI 가 자료에서 활동 · 경험을 채워 주지만, 저장된 경험은 **사용자의 기록**이다. 그 자리에서 바로 고치고, 더하고, 지울 수 있어 보여야 한다.
- **AI 는 유능한 동료로 보인다.** 「자료 넣기」가 입구이고, AI 가 무엇을 몇 개 찾았는지 짧게 말한다. 라벨만 붙이고 끝내지 않는다.
- **출처 상태는 지우지 않고 낮춘다.** 「원문 확인 / 내가 입력 / 확인 필요」와 AI 해석 표시는 고정 항목이다(SPEC §0 · ADR-002). 평소 화면에선 조용히, 「확인 필요」만 눈에 띄게, **꺼내 쓰는 순간(지원 문항 추천)에 크게** 보인다.
- **쌓이는 느낌은 주되 재촉하지 않는다.** 줄어들지 않는 누적 숫자는 좋다. 주간 비교 · 빈 요일 · 스트릭 · 점수는 없다 — 몇 달 만에 와도 편한 화면.

## 색

한 화면의 대부분은 흰 바탕 · 먹색 글 · 살짝 초록 기운이 도는 종이색 회색이다. 색은 **역할이 있는 곳에만**, **작은 면에만** 쓴다.
노트의 인덱스 탭 · 견출지처럼, 채도를 낮추고 온도를 다르게 한 두 색이다 — 연두는 노란 기운, 하늘은 회색 기운.

| 토큰 | 값 | 쓰는 곳 | 쓰지 않는 곳 |
| --- | --- | --- | --- |
| `primary` 연두 | `#4A7A2C` | 주 버튼(「자료 넣기」) · 고른 활동 · 진행 중 점 · 기간 띠 | 넓은 면, 경고 · 오류, 카드 면 전체 |
| `primary-soft` | `#EDF3E2` | 고른 활동 줄 바탕 · 기간 띠 바탕 | |
| `evidence` 하늘 | `#2E6487` | 근거 열기 · 원본 파일 이름 · 원문 확인 체크 — **「원문 · 근거」의 색** | 버튼 · 장식 |
| `review` 호박 | `#9A5410` 글자 / `#FDF1E3` 바탕 / `#E9A35A` 점선 | 「확인 필요」 하나에만 | 다른 상태 · 분류 |
| `error` | `#B4321F` | 분석 실패의 이유 글자 · 아이콘 | 면 칠하기 |
| `ink` · `body` · `muted` | `#20231E` · `#3A3E37` · `#676B62` | 글자 단계 | 순수 검정 · 차가운 회색 |
| `paper` | `#F6F6F1` | PC 사이드바 바탕 | 본문 바탕 |
| `hairline` | `#E3E3DA` | 줄 구분 · 패널 경계 | |

- **연두는 한 화면에 두 곳까지**(주 버튼 + 고른 활동). 기간 띠는 연두를 옅게 섞어 쓴다.
- 분류 · 태그에 색을 따로 주지 않는다. 나중에 활동 분류 색이 필요하면 연두 · 하늘 두 계열 안에서, **노랑 · 주황은 쓰지 않는다**(「확인 필요」 호박과 겹친다).
- 연두 위 흰 글은 15px 이상 · 600 굵기(대비 5.1). 하늘 글자는 흰 바탕에서 대비 6.4.
- 어두운 화면은 아직 만들지 않는다.

### AI 가 짠 느낌이 나는 것 — 피한다

- 채도가 같은 파스텔 여러 개로 카드 면 전체를 칠하기(Tailwind 기본 `sky-100 · green-100 · pink-100` 같은 조합)
- 검은 알약 주 버튼 + 파스텔 카드 · 모든 블록에 같은 둥근 상자 + 그림자
- 그라데이션 · 반짝이(✨) 아이콘 · 보라-파랑 계열 주 색

## 배치 · 간격 · 모서리 · 그림자

- 간격은 4 의 배수: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. 묶음 안은 8~12, 묶음 사이는 24~32.
- **카드보다 구분선.** 목록(활동 줄 · 경험)은 상자로 감싸지 않고 `hairline` 한 줄로 나눈다. 상자는 떠 있는 것(패널 · 시트 · 메뉴 · 대화창)에만.
- 모서리: 버튼 · 입력 8, 떠 있는 상자 14, 하단 시트 위쪽 20, 꼬리표 · 해시태그 full.
- 그림자는 `float` **한 단계**뿐 — 메뉴 · 시트 · 대화창 · 끄는 중인 카드. 나머지는 평평하다.
- 덮개(모달 뒤)는 `scrim` 45%.

## 아이콘

- **Phosphor Regular 한 세트**만. 직접 그리지 않고, 다른 세트를 섞지 않는다.
- 의미가 있는 곳에만: 분석 횟수를 쓰는 버튼(`sparkle` — 글자 앞 하나, 글자와 같은 색, 채움 · 그라데이션 · 움직임 없이. 뜻은 SPEC S-15 · FE#434) · 근거(`quotes`) · 파일(`file-text`) · 원문 확인(`check`) · 확인 필요(`warning-circle`) · 고치기(`pencil-simple`) · 추가(`plus`) · 메뉴(`dots-three`) · 닫기(`x`) · 다시 시도(`arrows-clockwise`) · 끌기(`dots-six-vertical`) · 메뉴 항목(`rows` 타임라인 · `chat-circle-text` 지원 문항).
- 제목 옆 장식 아이콘, 이모지, 장식용 반짝이 없음 — 반짝이는 위 「분석 횟수를 쓰는 버튼」 뜻으로만 쓴다.

## 컴포넌트

### 사이드바 `sidebar` (PC)
폭 240, `paper` 바탕, 오른쪽 `hairline`. 위에서부터:
1. 이름 「차곡」(가칭, 22 / 700) — 확정 전이라 옆에 작게 「가칭」
2. 주 버튼 「자료 넣기」(폭 가득) + 한 줄 「README · 회고 · 노트를 넣으면 AI 가 읽고 활동과 경험을 찾아 정리해요.」
3. 메뉴: 타임라인(고른 것 — 흰 면 + `hairline` 테두리) · 지원 문항(다음 스프린트 — 흐리게 「곧」)

모바일은 사이드바 대신 위 막대(높이 56, 이름만) + 오른쪽 아래 떠 있는 「자료 넣기」.

### 화면 머리
- 제목 `display` 「경험이 차곡차곡 쌓이고 있어요」
- 아래 한 줄 「지금까지 활동 N · 경험 M — 필요할 때 꺼내 쓰세요」. **누적 숫자만** — 「이번 주」 · 「지난주보다」 · 요일 체크는 두지 않는다.

### 연도 묶음 `year-group`
연도(`title-md`, tabular) + 「활동 N」(`label` muted). 최근 연도가 위. 아래 `ink` 한 줄.

### 활동 줄 `activity-row`
- 한 줄: 이름(`title-md`) · 기간(`body-sm` muted) · 「경험 N」 · 오른쪽에 **기간 띠**.
- 줄 배치는 화면 폭이 아니라 **타임라인 칸의 폭**으로 정한다(컨테이너 쿼리 576px). PC 에서 사이드바 · 세부 패널이 함께 열려 칸이 좁으면 띠가 이름 아래로 내려간다.
- **기간 띠** `period-band`: 그해 1–12월을 12칸으로 나눈 얇은 띠(높이 6). 활동한 달은 연두를 옅게, 진행 중이면 오른쪽 끝을 흐리게, 해를 넘으면 끝을 막지 않는다. 같은 연도의 띠가 세로로 줄지어 있어서 **겹침은 띠끼리 비교해 읽는다**(S-07). PC 는 띠 끝을 끌어 기간을 고친다(S-17).
- 해를 넘는 활동은 다음 해 묶음에도 **흐린 줄**(이름 · 「2024년부터 이어짐」 · 띠)로 나온다.
- **놓을 곳**(끌어다 놓기): `ink` 점선 테두리 + `surface-strong` 바탕 + 안내 한 줄 「여기에 놓으면 이 활동으로 옮겨요」.
- 기간을 모르는 활동은 맨 아래 「기간 모름」 묶음.
- 호버 `surface-soft`, 고른 줄 `primary-soft` 바탕 + 이름 `primary-active`.

### 활동 세부 `activity-detail`
- PC: 오른쪽 패널(폭 440, `hairline` 경계, 타임라인은 옆에 남는다). 모바일: 전체 화면, 위에 「‹ 타임라인」.
- 머리: 활동 이름(`title-lg`) + 메뉴(⋯: 활동 고치기 · 다른 활동과 합치기) / 기간 / **「이 활동을 만든 자료」** — 근거들의 원본 이름을 모아 `evidence` 색 파일 링크로.
- 몸: 경험 목록. 처음 3개 + 「나머지 N개 더 보기」. 맨 아래 「+ 경험 직접 추가」(S-11).

### 경험 `experience-item` — 주인공
```
채팅 메시지가 늦게 도착하는 문제를 폴링에서 WebSocket 으로      수정  ⋯
바꿔 해결했다                                            ← body-md
✓  팀  (#문제 해결) (#기술 구현)                      ❝ 근거 1  ⌄    ← label · evidence
```
- 상자 없이, 경험 사이는 `hairline`.
- **메타 줄**(label) — 앞에서부터 출처 상태 · 수행 주체 · 역량:

  | 무엇 | 표시 |
  | --- | --- |
  | 원문에서 확인 | `evidence` 색 **작은 체크 하나**. 글자 「원문 확인」은 읽기 도구 · 툴팁으로 |
  | 내가 입력 | `muted-soft` 연필 + 「내가 입력」 — 고쳤거나 직접 넣은 경험 |
  | 확인 필요 | **유일하게 색이 있는 꼬리표** — `review-soft` 바탕 · `review-line` 점선 · 느낌표 + 「확인 필요」 |
  | 수행 주체 | 「나」는 기본이라 **숨긴다**. 「팀」 · 「알 수 없음」만 글자로 |
  | 역량 | **해시태그** `#문제 해결`(badge, full 모서리). AI 가 붙인 것은 `muted-soft` **점선** 테두리(툴팁 「AI 가 붙인 역량이에요 — 해석이라 고칠 수 있어요」, 읽기 도구엔 「AI 가 붙인 역량:」), 내가 고른 것은 `hairline` 실선 + `surface-soft` 바탕 |

- **고치기**(S-10): 「수정」을 누르면 그 자리에서 입력칸이 되고 「저장 · 취소」. 저장하면 상태는 「내가 입력」, 근거는 그대로 남는다.
- **⋯ 메뉴**: 고치기 · 다른 활동으로 옮기기 · 지우기.
- PC 에서는 경험 왼쪽에 호버 때만 끌기 손잡이(S-12).

### 근거 `citation`
- 「❝ 근거 N」을 누르면 경험 아래에 펼친다(모바일은 하단 시트).
- `surface-soft` 면 안에: 파일 이름(`evidence`, `label`) · 「5번째 줄」(muted) · 발췌문(`body-sm`, 왼쪽 `hairline` 세로줄).
- `matched: false` 면 발췌문 아래 `review` 글자로 「원본에서 이 문장을 그대로 찾지 못했어요. 맞는지 확인해 주세요.」

### 지원 문항 추천 (스프린트 2 — 자리만)
출처 상태를 **크게** 보이는 곳. 요구사항마다 「근거 있음 / 일부 / 자료에서 확인 안 됨」(S-19), 추천마다 근거 발췌 · 「내가 입력」 보완. 「자료에서 확인 안 됨」을 「부족한 사람」처럼 보이게 하지 않는다. 입구 문구 후보: 「어떤 경험을 꺼내볼까요?」(디자인 시안 홈).

### 버튼

말투는 「~해요」. 가운데 정렬 덩어리 하나, 아이콘은 하나만.

| --- | --- | --- |
| 첫 사용(활동 0) | 어떤 일을 해 왔나요? | 자료 넣기 — 「AI 가 읽고 … 원문 근거와 함께 연도별로 쌓아 둘게요」 · README · 회고 · 노트 예시를 회색 꼬리표로 |

## 반응형

| 폭 | 바뀌는 것 |
| --- | --- |
| < 1024 | 위 막대 한 줄(로고 · 작업 상태 · 검색 · 종 · 계정) + 아래 탭바(홈 · 내 경험 · + 추가 · 지원 · 연결, 아이콘 + 글자 · 아래로 내리면 숨고 입력 중에는 없다) · 타임라인 목록 → 활동을 누르면 전체 화면 세부 → 근거는 하단 시트. 옮기기는 ⋯ 메뉴로(끌기 없음) |

## 말투

- 사용자 쪽 말로: 「경력 데이터 등록」 대신 「어떤 일을 해 왔나요?」, 「역량 부족」 대신 「확인해 보면 좋아요」, 「자소서 생성」 대신 「이번엔 어떤 경험을 꺼내 볼까요?」.
- 쌓임 · 꺼내 쓰기의 말: 「차곡차곡 쌓이고 있어요」 「필요할 때 꺼내 쓰세요」 「거창하지 않아도 좋아요」.
- 칭찬 · 과장 · 단정 없음(「대단해요」 「핵심 역량」 금지).
- 오류는 무슨 일이 있었는지 + 무엇을 하면 되는지. 사과문 없음.
- 사실이 아닌 약속은 쓰지 않는다 — 예: 「나의 경험은 나에게만 보여요」는 로그인(S-14) 뒤에.

## 하지 말 것

- 상태 · 역량 · 주체를 모두 색 알약으로 — 색이 있는 꼬리표는 「확인 필요」 하나
- 연두를 세 곳 넘게, 연두 · 하늘을 경고색으로
- 분류마다 다른 파스텔로 카드 면 칠하기, 모든 블록에 같은 둥근 상자 + 그림자
- 「이번 주 N개」 「지난주보다 +N」 · 요일 체크 · 스트릭 · 점수
- 사진 · 일러스트로 일기장처럼 꾸미기 — 원본 자료(파일)가 그 자리에
- 그라데이션 · 장식용 반짝이 아이콘(분석 버튼 표시 말고) · 고정폭 글꼴 장식
- 마인드맵 · 그래프 모양(SPEC F-03), 한 해짜리 가로 간트(여러 해를 한눈에 못 본다)

## 미결정 (ETC#19)

- 첫 화면을 홈으로 할지 — 기본값: 타임라인. 홈의 「꺼내볼까요」 입력칸은 스프린트 2 지원 문항 입구로
