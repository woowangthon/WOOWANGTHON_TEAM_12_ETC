# 차곡 시안 2 — 디자인 담당 시안 + PM 피드백(ETC#19)

배치(UX)를 보고 이야기하기 위한 **정적 시안**이다. 서버 · AI 호출 없이 예시 데이터(SAMPLE)로 그린다. 실제 앱(FE)은 이걸 보고 정한 뒤에 옮긴다.

- 열어 보기: `index.html`(홈) · `timeline.html`(타임라인 + 세부) · `apply.html`(지원 문항 — 꺼내 쓰기). 「자료 넣기」 · 「생각난 김에 한 줄」은 대화창
- 오른쪽 아래 주황 **「이번 피드백 보기」** — 디자인 담당 시안에서 바꾼 자리마다 번호와 이유. 보라 번호는 PM 이 정할 것
- `styles.css` · `main.js` · `assets/` 는 디자인 담당 시안(https://woowangthon.vercel.app/) 그대로다. 바꾼 건 `chagok.css`(덧씌우기) · `mock.js`(화면 · 예시 데이터)에만 있다
- PC 기준. 모바일은 아직 없다
