# 차곡 시안 4 — 디자인 담당 시안 + PM 피드백(ETC#19)

배치(UX)를 보고 이야기하기 위한 **정적 시안**이다. 서버 · AI 호출 없이 예시 데이터(SAMPLE)로 그린다. 실제 앱(FE)은 이걸 보고 정한 뒤에 옮긴다.

- 열어 보기: `index.html`(홈) · `experience.html`(내 경험 — 타임라인 · 목록 · 자료별 + 세부) · `apply.html`(지원서 — 문항 탭 · 꺼내 쓸 경험 · 초안 · AI 동료 패널). 사이드바 「+ 추가」 · 알림 종 · 접기 버튼도 눌러 볼 수 있다
- 오른쪽 아래 주황 **「이번 피드백 보기」** — 지난 시안에서 바꾼 자리마다 번호와 이유. 보라 번호는 PM 이 정할 것
- `styles.css` · `main.js` · `assets/` 는 디자인 담당 시안(https://woowangthon.vercel.app/) 그대로다. 바꾼 건 `chagok.css`(덧씌우기) · `mock.js`(화면 · 예시 데이터)에만 있다
- PC 기준. 모바일은 아직 없다

## 시안 3 의 구조

| 자리 | 하는 일 |
| --- | --- |
| 홈 | 입력 하나 + 아래 모드: **물어보기**(한 줄 질문 → 근거 달린 경험) · **지원서 만들기**(문항 · 공고) · **쌓기**(자료 · 한 줄). 보내기 옆은 모델 고르기 자리(P1). 아래 「이어서」 세 칸 |
| 내 경험 | 같은 경험을 보는 방법 셋(타임라인 · 목록 · 자료별) + 거르기(분류 · 저장한 것 · 확인 필요) + 오른쪽 세부 |
| 지원서 | 지원처 하나 + 문항 여러 개(SPEC S-18). 문항 탭 → 답(맨 위, 근거 점검) → 참고 경험(접었다 펴기). 오른쪽 AI 동료는 대화처럼(문항 읽기 → 빠진 것 묻기 → 보완 쌓기 → 초안) |
| 사이드바 | + 추가(자료 가져오기 · 직접 기록하기 · 새 지원서) · 홈 · 내 경험 · 지원서 목록. 접으면 둥근 아이콘 레일 + 말풍선 |
| 알림 | 확인 필요 · 분석 끝 · 추천 끝 — 재촉하는 알림은 없다 |
